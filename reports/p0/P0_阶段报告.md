# P0 环境、规模与下载试跑报告

日期：2026-09-23。状态：**P0 数据侧通过；运行环境待安装。**

## 工程结果

- 官方 API 按创建月份统计，2025 年共有 **3,655,040** 条记录。
- 月度范围为 255,364—348,180 条，完整明细见 `p0_sample_50000.json`。
- 使用 `(created_date, unique_key)` 有序游标分 5 页获取 50,000 条真实记录。
- 下载与 gzip 写入总耗时 **18.125 秒**，约 **2,758.62 条/秒**。
- 选定 20 个字段后，未压缩 JSONL 为 31,188,411 字节，gzip 为 2,522,410 字节。
- 按本样本粗略外推，2025 年同字段原始 gzip 约 0.172 GiB。该值不包括 Parquet、MySQL、索引、临时空间、日志，也不能代表全字段体积。
- E 盘试跑时剩余约 **370.69 GiB**，数据空间不是当前阻塞点。

## 独立校验

`validate_p0_sample.py` 从 gzip 重新读取并验证：

- 50,000 行与下载报告一致；
- 50,000 个业务主键，无重复；
- `(created_date, unique_key)` 严格递增；
- 解压后内容 SHA256 与下载阶段一致；
- 约定的核心字段均在样本中出现且本批没有空值。

样本覆盖 2025-01-01 00:00:12 至 2025-01-05 04:07:45，是一月按时间排序的前 5 万条，不是随机样本，也不是完整一月。因此状态和机构比例只用于检查，不作为业务结论。
