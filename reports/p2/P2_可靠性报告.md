# P2 可靠性报告

状态：**通过**。

测试使用 `P2_SYNTHETIC_*` 明确标注的合成工单，结束后自动清理；不把模拟变化写成 NYC 真实业务变化。原始结果见 `reliability_tests.json`。

| 场景 | 验证结果 |
|---|---|
| 同一输入重跑 | current 1→1，observation 1→1 |
| Open→Closed 内容变化 | current 更新为 Closed，observation 1→2 |
| COMMIT 后回执丢失 | 重连找到 COMMITTED checkpoint；current/observation 均保持 1 |
| 候选发布失败 | 活动版本始终为 `2025-baseline-v1`，失败候选未激活 |
| 正式成功任务重跑 | 返回 `ALREADY_SUCCEEDED`，未重复加载 |

实现要点：`run_key` 唯一、业务字段内容 hash、observation 的 `(unique_key, content_hash)` 唯一约束、分块事务 checkpoint、候选版本核验后短事务激活。

边界：本阶段验证的是数据库侧幂等与恢复；NYC API 的真实历史修正仍需跨多个上游更新周期观察。
